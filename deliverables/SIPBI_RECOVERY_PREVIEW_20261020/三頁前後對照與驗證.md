# SIPBI 三個代表頁：修正版預覽

本輪交付是供視覺方向審閱的三頁實作，尚未完成十二頁改版，也未將修正版覆寫至原安裝目錄。

本機預覽：[開啟 SIPBI 修正版](http://localhost:55152/)。由左側導覽選擇 D04、D11、D15。其餘九頁沿用本輪開始時的版本。

## 前後差異

「前」是本輪開始時、被指出雷同的版本；「後」是本輪三頁修正版。更早的版面原始碼只作為設計參考，不直接當成正確實作還原。

| 頁面／執行者 | 分析問題 | 本輪修正 |
|---|---|---|
| D04／AGY | 營收由哪些類別組成，主力產品的規模與毛利如何？ | 類別環形組成＋產品營收長條／毛利率菱形，明示不同尺度；類別負值、空值或非正總額改用金額比較；固定成員顏色。 |
| D11／Grok | 客戶營收集中在多少客戶，長尾分布如何？ | 恢復單一 Pareto：前20名與全部客戶切換；全體模式先顯示完整分布，再用滑桿縮放。累積占比分母始終為全部所選客戶。 |
| D15／Muse Code | 月實績與不同累積期間如何變化？ | 一張主圖切換當月柱狀、近3月總和、近12月總和、年度累計；保留完整時間序列與表格，跨年累計分段。 |

三方各在隔離副本修改一頁；Codex 負責整合、數據與瀏覽器檢查，並修正標籤、顏色、標記對比、手機標題換行、全體客戶初始視窗等細節。三方回報的原始設計與結果保留於 reviews。

## 實際檢查與界線

- TypeScript＋Vite 最終建置通過；7組圖表語意檢查通過，包含組成合計、負值／空值／零總額、穩定色彩與鍵值、Pareto分母、完整滾動總和與跨年斷點。此檢查直接評估實際TSX，使用替代資料hook；不當作瀏覽器證明。
- 實際瀏覽器操作1440×1000與390×844；三頁中文淺色，另檢查D04／D11英文深色。手機圖表局部捲動，頁面本身無橫向溢出；目前分頁未記錄console error。
- 實際點擊D04產品長條，開啟BZT-06的25筆客戶維度彙總；點擊D11長條，帶入客戶00020|100048；D15最早月份長條切換至202401，近3／12月KPI保留空值。
- D11公司00020篩選後，母體由238家更新為50家；202610無資料月份顯示no_data，未殘留舊圖。
- 三頁預覽API均回傳同一切片淨銷售額16,234,174.4534 USD，來源為原JDE Sales Cube；132筆產品CSV的匯出量值逐筆對上API。
- 檔案雜湊確認應用只改三個頁面；原安裝目錄來源未被覆寫。未修改SQL／SSAS資料或查詢、共用型別、篩選、路由與套件設定。本輪沒有重新執行165組公司月份等全量SQL核對，不能將以前結果當作這次新增驗證。
- 尚未將方向套用至其餘九頁，也尚未取得本輪視覺方向的使用者確認。手機共用篩選器仍占較多垂直空間，本輪未變更該共用區塊。

完整記錄見 verification/page-semantics.json、api-final.json、browser-final.json、scope-final.json。本輪保留原有大型ECharts bundle，建置仍有chunk size提示。

## 啟動與環境限制

Windows目前保留TCP 5141..5240，原5150及原預覽5152在續作時均出現listen EACCES。因此本輪暫用 **127.0.0.1:55152** 預覽，API用 **127.0.0.1:55150**；沒有變更系統保留埠、防火牆或原應用的5150設定。這是本機方向預覽，尚未部署為區域網路正式版本。

目前的預覽可直接開啟。需要重新啟動時，在PowerShell執行本資料夾下 `preview/start-preview.ps1`；停止執行 `preview/stop-preview.ps1`。停止腳本只處理同一資料夾啟動並記錄的程序，會核對PID、啟動時間及Node路徑，不停止其他服務。若埠已有服務，啟動腳本會保留既有程序。

preview/app包含完整原始碼與已建置前端，不包含node_modules、憑證或runtime。執行預覽需要本機既有Node與SQL Server／SSAS環境。修改後重建，可在preview/app/frontend執行npm ci與npm run build。

如需重跑圖表語意檢查，先安裝上述既有前端依賴，再從交付根目錄執行 `node verification/verify-page-semantics.cjs`。verification/live-data-final.json為本輪Cube查詢取得的虛擬資料測試快照。
