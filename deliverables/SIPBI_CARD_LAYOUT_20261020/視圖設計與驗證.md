## 手冊採用方式

- 三個原始檔均已讀取：Markdown 全文、HTML 文字與嵌入圖片結構、PDF 全 18 頁文字及封面渲染；Card Layout、KPI 情境化參考圖亦已視覺檢查。來源大小與 SHA256 記錄於 `reference/sources.json`；Markdown 副本在 `reference/設計手冊.md`。
- 保留 React／TypeScript／ECharts，新增真實月度迷你趨勢、28–32px KPI 主數字、統一邊框與留白；營收使用藍色、成本／比較使用灰色、毛利率使用琥珀色。綠紅主要用於期間增減與實際風險。
- 雙軸使用不同圖形，軸刻度與系列同色。金額柱保持零基線並容納負值；散點毛利率軸清楚顯示實際資料範圍。座標保留來源精度，僅標籤與提示格式化。
- 七個類別採扁平矩形樹圖，不虛構產品到類別的父子關係。圓環模式採 Top4＋其他，灰色其他置後，圖例與切片一致，揭露其他所含類別；四捨五入後顯示佔比可能相差 0.1 個百分點，底層數值未調整。
- 不套用缺乏資料的地圖、階段漏斗、預算進度、迴歸線或市場占有率。產品矩陣為內部統計比較，瀑布為算術貢獻。
- 月份與公司為主要篩選，其餘五個維度置於可展開區；穩定成員鍵值、已套用條件、重設、下鑽、完整明細與證據卡保留。

## 交付及限制

- 應用原始碼與既有後端位於 `preview/app/`；前端原始碼僅變更 16 個檔案（12 頁、KpiCard、EChartsContainer、SlicerBar、index.css）。API、路由、型別、資料來源程式、計算 helpers 與套件鎖定檔保持基準內容。完整 SHA256 與原專案未變更的檢查在 `verification/scope.json`。
- 使用 `preview/start-preview.ps1` 開啟本機檢閱版（前端 55154、API 55150）；`preview/stop-preview.ps1` 僅停止該腳本有記錄且 PID／啟動時間／執行檔吻合的程序。既有 API 若重用，停止腳本不會停止它。
- Windows 目前仍將 5141–5240 列入 TCP 排除範圍，涵蓋原 5150。這輪未變更系統排除埠、防火牆或區域網路設定。55154 為 localhost 檢閱服務，尚未替換原安裝版或完成 LAN 部署。
- 資料為合成示範資料；免登入、五家公司共用主檔，帳號權限仍未實施。雲端 AI 本輪未呼叫；預覽代理僅允許 GET／HEAD。
- 未宣稱全組 SQL/Cube 165 個公司月份重新核對、SSAS 中斷演練、全安全稽核或使用者視覺驗收。此輪重點是十二頁視圖與互動，後端維持原樣。
- 自動核准審查起初因外部模型的資料傳送授權不夠具體而拒絕啟動；取得你明確同意後，才將前端、契約及設計參考送交 AGY／Muse Code。未傳送憑證、資料庫資料或密碼。
